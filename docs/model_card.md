# OpsPulse baseline model card

## Model purpose

Demonstrate a transparent baseline for prioritizing CRM leads for human review. It is a
portfolio/learning artifact, not a production decision system.

## Data

- 800 fully synthetic lead records generated by `generate_sample_data.py`.
- No personal data, real customer records, or Apple information is included.
- Target: `converted` (binary).
- Model inputs: region, industry, company size, lead source, response time, interactions,
  and previous purchases.
- Excluded fields: sales stage and deal value, to reduce direct target leakage.

## Evaluation method

- Stratified 75% / 25% train/test split.
- Fixed random seed: 42.
- One-hot encoding for categorical features.
- Standardization for numerical features.
- Logistic regression with balanced class weights.

## Observed hold-out metrics

| Metric | Value |
|---|---:|
| Accuracy | 0.640 |
| Precision | 0.505 |
| Recall | 0.630 |
| F1 | 0.561 |
| ROC-AUC | 0.690 |

These values are generated from one synthetic dataset and one split. They are not evidence
of expected performance on real CRM data and should not be used as a business performance
claim.

## Intended use

- Demonstrate model development and evaluation workflow.
- Explore how response speed, engagement, lead source, and account attributes relate to
  a synthetic conversion outcome.
- Produce a probability score for demonstration and human review only.

## Out-of-scope uses

- Automatically rejecting leads or customers.
- Making decisions about access to services, credit, employment, or other high-impact
  outcomes.
- Claiming production accuracy from synthetic data.

## Risks and mitigations

- **Synthetic-data gap:** validate on representative historical data before any real use.
- **Potential group differences:** evaluate errors and calibration across relevant groups.
- **Data privacy:** minimize personal data, apply access controls, retention policies, and
  approved lawful processing.
- **Model drift:** monitor input and outcome distributions over time.
- **Human oversight:** keep business decisions with trained reviewers and documented rules.
